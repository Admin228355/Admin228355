# Togetherly Free (форк)

Бесплатная сборка [Togetherly](https://github.com/THET1ME-1/Togetherly) (GPL-3.0).

## Что изменено
- **Togetherly+ открыт у всех**: календарь цикла, новый каталог виджетов, свои темы (пикер цвета и цвет из фото), кружочки любой формы, файлы до 200 МБ.
- **Всё, что продавалось за монеты, открыто**: темы, фоны холста, значки профиля, маскоты и паки настроений (кроме наградных значков Sponsor/Helper и авторских паков, которые продаются за деньги на сервере автора).
- **Рекламы нет**: баннеры, межстраничная реклама и ролики за монеты не загружаются, SDK рекламы не инициализируется.
- **+10 новых палитр**: Сакура, Фуксия, Коралловая, Сиреневая, Индиго, Изумрудная, Оливковая, Карамельная, Васильковая, Небесная.
- Отдельный ID приложения `com.togetherly.love.free` и название «Togetherly Free»: ставится рядом с оригиналом.
- Приложение не предлагает обновиться до APK оригинала.

Всё переключается одним флагом `lib/config/free_edition.dart` (`--dart-define=FREE_EDITION=false` возвращает поведение оригинала).

## Где взять APK
Вкладка **Releases** репозитория, файл `…-arm64-v8a.apk`. Собирает workflow `.github/workflows/build-free-apk.yml` при каждом пуше.

## Ограничения
- Приложение работает с сервером автора (PocketBase). Что проверяет сам сервер, клиент не меняет. Для полной независимости подними свой сервер (`pocketbase/`) и собери с `--dart-define=PB_URL=…`.
- Пуши FCM и вход через Google в этой сборке не работают: нужны ключи Firebase и Google именно под этот ID приложения. Вход по почте работает, уведомления идут через фоновый канал приложения.
- Без секретов подписи (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) каждая сборка подписывается новым отладочным ключом, и новую версию нельзя поставить поверх старой.
