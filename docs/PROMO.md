## 4PDA (тема в «Android — программы»)

**Название:** TogetherForever — приложение для пар (форк Togetherly без рекламы)

**Описание:**
TogetherForever — приватное пространство для двоих: общие воспоминания (фото, видео,
места, музыка, фильмы), капсула времени, секретные воспоминания под PIN, чат с
голосовыми сообщениями и видео-кружочками, совместное рисование и раскраски,
настроения, карта «Где мы» в реальном времени, виджеты на рабочий стол, календарь
цикла, маскот пары, совместный просмотр видео с голосовой связью.

**Особенности версии:**
- свободный форк Togetherly (GPL-3.0);
- все функции Togetherly+ и все покупки за монеты открыты бесплатно;
- реклама полностью удалена (рекламные SDK не инициализируются);
- 10 новых цветовых тем, своя тема из цвета или фото;
- данные на собственном сервере (инструкция и установщик в репозитории).

**Требуется Android:** 5.0+ · **Русский интерфейс:** да · **Скачать:** ССЫЛКА

Hi! I've published TogetherForever, an open-source (GPL-3.0) fork of the couples app Togetherly.

## Reddit — r/selfhosted (EN)

**Title:** TogetherForever — self-hosted private space for couples (PocketBase + Postgres + Centrifugo, one-command install)

TogetherForever is a GPL-3.0 fork of the Togetherly couples app, set up for self-hosting.
The whole backend is one `docker compose` stack: PocketBase (auth, files, access rules,
JS hooks), a FastAPI "hotpath" service on Postgres for the busy collections (chat,
memories, pairs), Centrifugo for realtime and Caddy for automatic HTTPS.
`server/install.sh your.domain you@mail` handles installation. Setting the repo
variable `PB_URL` makes GitHub Actions build an APK pointed at your server.

Repo: ССЫЛКА
