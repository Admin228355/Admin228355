# Блоки-маскировка кубического ландшафта (Minecraft Java 1.16.5)

Формат **Java Block/Item** (JSON + PNG 256×256), стиль как у мебели: приглушённая трава, тёмная земля, камень во мху.
Ставятся так же, как мебель: через подмену `paper` по `CustomModelData`, в масштабе 1:1 (голова стойки для брони или невидимая рамка на полу).

| Модель | Файл | CMD | Куда ставить |
|---|---|---|---|
| Склон 45° | `terrain_slope` | 9301 | в воздух перед ступенькой высотой 1 блок, подъём в сторону юга (+Z модели) |
| Склон, внутренний угол | `terrain_slope_inner` | 9302 | во внутренний угол ступеньки (подъём на юг и на восток) |
| Склон, внешний угол | `terrain_slope_outer` | 9303 | у выступающего угла холма |
| Свисающая трава | `terrain_grass_overhang` | 9304 | в воздух над краем обрыва, трава свешивается по северной стороне блока ниже |
| Свисающая трава, угол | `terrain_grass_overhang_corner` | 9305 | то же, на углу (север + запад) |
| Каменная осыпь | `terrain_cliff_rocks` | 9306 | в воздух перед отвесной стенкой: камни прилегают к ней (южная сторона модели) |
| Валуны | `terrain_rocks` | 9307 | на землю, чтобы разбить ровный край |
| Куст травы | `terrain_grass_tuft` | 9308 | на землю, вдоль стыков блоков |
| Земляной бугор | `terrain_mound` | 9309 | на землю, сглаживает плоские участки |

Поворот под нужную сторону делает стойка/рамка (поворот сущности), модель менять не надо.

Склоны собраны из наклонённых на 45° элементов (разрешено в 1.16.5). Всё, что выходит за пределы блока,
отрезано прозрачностью текстуры, поэтому каждая деталь сама по себе замкнутая и не зависит от соседей.

`/give @p minecraft:paper{CustomModelData:9301}`

Пересборка: `cd ../furniture-1.16.5/generator && SET=terrain TEX_SIZE=256 python3 build.py`.
