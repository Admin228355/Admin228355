# Helicopters — управляемые вертолёты для Paper 26.1.2

Плагин добавляет на сервер вертолёты с моделями из Blockbench. Модов у игроков не нужно, только
ресурспак, и плагин отдаёт его сам.

| Тип | Модель | Двери | Мест | Прочность | Скорость |
|---|---|---|---|---|---|
| `blackhawk` | `blockbench/black_hawk/black_hawk.bbmodel` | 2 сдвижные двери по бортам, грузовая рампа | 12 | 140 | ~105 км/ч |
| `mi8` | `blockbench/mi8_helicopter/mi8_helicopter.bbmodel` | боковая дверь, задние створки, дверь кабины | 10 | 100 | ~80 км/ч |

## Что умеет

- **Физическая форма.** Пока вертолёт стоит с выключенным двигателем, вокруг салона стоят невидимые
  барьеры (пол, борта, крыша, хвостовая балка). В вертолёт можно зайти через боковую дверь или
  задние створки и ходить внутри.
- **Двери.** ПКМ по двери открывает её с анимацией. Кнопки есть снаружи и изнутри. Проёмы
  в коллизии открываются вместе с дверями: при опущенной рампе Black Hawk в салон можно зайти сзади.
- **Сиденья.** Пилот, второй пилот и места в салоне. ПКМ по сиденью — сесть.
- **Склад.** ПКМ по ящикам в салоне открывает инвентарь на 54 слота. Он сохраняется в
  `helicopters.yml`.
- **Полёт.** Винт раскручивается и тормозит, есть подъёмная сила, инерция, наклон корпуса при
  разгоне и повороте, столкновения с блоками, посадка.
- **Урон.** Корпус повреждается от жёстких посадок, ударов лопастями о блоки и ЛКМ других игроков.
  При повреждениях идёт дым, при нуле прочности вертолёт взрывается и груз выпадает.
- **Эффекты.** Звук винта, пыль под винтом у земли, HUD пилота в строке действий (обороты,
  скорость, высота, прочность корпуса).
- **Сохранение.** Вертолёты, их груз и состояние дверей переживают перезапуск сервера.

## Управление (пилот)

| Клавиша | Действие |
|---|---|
| Пробел | запуск двигателя / набор высоты |
| Shift | снижение (на земле — выйти) |
| W / S | вперёд / назад |
| A / D | боком влево / вправо |
| Ctrl (бег) | форсаж |
| Мышь | поворот вертолёта (нос следует за взглядом) |

Пассажиры выходят по Shift только когда вертолёт на земле (это настраивается в `allow-jump-out`).

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/heli spawn [blackhawk\|mi8]` | heli.admin | поставить вертолёт туда, куда смотришь (без аргумента — `default-type` из конфига) |
| `/heli remove` | heli.admin | удалить ближайший (груз выпадет) |
| `/heli repair` | heli.admin | отремонтировать ближайший |
| `/heli list` | heli.admin | список вертолётов |
| `/heli engine` | пилот | вкл/выкл двигатель |
| `/heli pack` | все | отправить ресурспак ещё раз |

Права `heli.use` (сесть, двери, склад) и `heli.pilot` (кресло пилота) по умолчанию есть у всех.

## Сборка

Нужны JDK 25 и интернет (Gradle скачает Paper API).

```bash
cd paper-plugin
./gradlew build          # Windows: gradlew.bat build
```

Готовый файл: `build/libs/helicopters-1.0.0.jar`. Положите его в `plugins/` сервера Paper 26.1.2.

Если Gradle не находит `paper-api`, впишите точную версию для 26.1.2 в `gradle.properties`
(список версий: https://repo.papermc.io, `io/papermc/paper/paper-api`).

## Ресурспак

Ресурспак `heli_resourcepack.zip` (оба вертолёта) лежит внутри jar. При старте плагин кладёт его в
`plugins/Helicopters/` и раздаёт встроенным HTTP-сервером на порту `8163`.

- Сервер не на локальной машине? Впишите внешний IP или домен в `resource-pack.public-host`
  и откройте порт.
- Либо загрузите zip на любой хостинг и впишите ссылку в `resource-pack.url`.

## Если что-то выглядит не так

- **Вертолёт летит хвостом вперёд или развёрнут:** в `config.yml` поставьте `model.yaw-offset: 0`.
- **Игрок сидит слишком высоко или низко:** подправьте `model.seat-y-offset`.
- **Панели корпуса стоят криво:** Java 26.1 умеет поворачивать элементы моделей по трём осям. Если
  порядок осей в игре отличается от Blockbench, откройте `blockbench/heli_lib.py`, поставьте
  `JAVA_ROTATION_ORDER = "XYZ"` (для Ми-8 — ещё и в `blockbench/mi8_helicopter/generate.py`) и
  запустите оба генератора: `python3 blockbench/black_hawk/generate.py` и
  `python3 blockbench/mi8_helicopter/generate.py`. Они пересоберут ресурспак прямо в
  `paper-plugin/src/main/resources/`, после этого пересоберите плагин.

## Как это устроено

- `blockbench/<тип>/generate.py` строит модель (общий код — `blockbench/heli_lib.py`) и одновременно:
  - экспортирует подвижные части (корпус, винты, двери, рампа) как модели предметов Java
    в `paper-plugin/resourcepack/` и собирает из папки `heli_resourcepack.zip`;
  - пишет `src/main/resources/types/<тип>.yml`: части и их анимации, двери, сиденья, кнопки, точки
    столкновений, форму коллизии и параметры полёта.
- Новый вертолёт = новый генератор, который пишет свой `types/<тип>.yml`. Код плагина при этом
  менять не нужно.
- Каждая часть показывается через `ItemDisplay`. Плагин каждый тик считает матрицу: положение и
  наклон корпуса, вращение винтов, анимация дверей.
- Сиденья — невидимые сущности, на которых сидят игроки. Кнопки — сущности `Interaction`.
- Координаты сидений и кнопок в `types/*.yml` заданы в единицах Blockbench, их можно подсмотреть
  прямо в редакторе.
